# SDM評估輔助規則

依2025年8月《SDM安全評估(2版)、風險評估及風險再評估實務操作手冊》摘要。操作前依第一類家內案件適用政策確認案件、兒少同住情況、照顧者、監護人、造成傷害者所在家戶、跨家戶情況及是否缺乏適切保護。不同角色分列。

## SDM-S 安全評估

整理當下可能造成嚴重傷害的立即威脅、兒少的無助狀態、照顧者保護能力及已採取行動、安全網絡、待確認資訊及安全計畫討論事項。立即危險優先依機關程序處理。正式安全判斷、安全計畫與安置由權責人員確認。

## SDM-R 風險評估

聚焦未來再次不當對待的可能性。列明風險相關資訊、來源、查證程度、待查題項、應補訪談或網絡資料，供後續處遇與服務密度討論。不得自行計分、推定風險層級或決定密度。

## SDM-RR 風險再評估

對照前次評估與本期服務資料，整理可觀察的行為及環境變化、持續問題、待查事項與督導討論重點，供結案評估參考。部分目標達成或家庭功能改善不足以判定可結案。

家庭功能25題用於優勢、需求及處遇方向。立即危險、未來風險與服務需求須分開描述。工具間不得換算分數。正式通報、安置、返家及結案等由權責人員依程序執行。
