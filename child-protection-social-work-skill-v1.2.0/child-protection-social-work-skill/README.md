# 兒保小尖兵 v1.2.0

臺灣兒少保護社工紀錄與評估資料整理助手。將專案置於支援 Agent Skills 的工具指定目錄，依平台要求以 child-protection-social-work 作為安裝資料夾名稱。入口為 SKILL.md。

| 模式 | 用途 |
|---|---|
| 標準版 | 完整訪視與會談紀錄 |
| 速寫版 | 精簡紀錄 |
| 督導版 | 紀錄檢視與督導回饋 |
| 教學版 | 紀錄改寫與新手訓練 |

例如「請用標準版整理以下訪視紀錄」或「請依25題架構列出已有依據及待查證事項」。另支援家庭處遇計畫、SDM三項工具資料整理及結案摘要。

references/ 收錄指定版本摘要及來源，templates/ 收錄輸出格式，examples/ 提供虛構練習。家庭功能採家庭13題、兒少12題；107年21題版僅供歷史比較。SDM採2025年8月指定版本。實務應核對機關規定。

於專案根目錄執行 `python -m unittest discover -s tests -v`。結構測試不驗證正式評分或模型輸出。

公開專案僅收錄自編摘要及虛構案例。原始手冊、空白表單與真實個案資料應存放於受控環境。正式評估及決策由權責人員審核。本專案尚未選定開放原始碼授權條款。
